Secret Tunnel

Give ChatGPT one folder on your computer.

ChatGPT runs in a datacentre and cannot reach your machine. Secret Tunnel runs a small file server locally and gives it a stable private HTTPS address, so ChatGPT can read — and if you allow it, edit — the files in a single folder you choose. Nothing is uploaded in advance.

What you need first

  • A free zrok account, for the tunnel. One token, entered once.
  • A ChatGPT plan that offers custom MCP connectors (developer mode). This is not available on the free tier.

Setting it up

1. Enable the tunnel

  1. Create a free account at myzrok.io.
  2. Copy your enable token.
  3. Paste it into the app and press Enable.

2. Pick a folder

  1. Press Select access folder.
  2. Choose a project folder — never a drive root, home folder or system folder.
  3. Choose Read, or Read+write to allow edits.

3. Wait for green

ChatGPT can reach it must say Connected. That means a real handshake succeeded through the public address — not merely that a process started. If it is red, the app tells you why.

4. Add it to ChatGPT

  1. Copy the MCP Address from the app.
  2. In ChatGPT: Plugins → New Plugin.
  3. Connection: Server URL, paste the address.
  4. Authentication: No Auth.
  5. Accept the warning, then Create.

Before you share it around

What What it means for you
The address is the password Anyone holding the full URL can read that folder, and write to it in Read+write mode. Do not paste it anywhere public.
Only one folder is exposed Nothing above or outside your chosen folder is offered, in either mode.
Closing the app closes the tunnel The address stops working until you open it again. Keep it open while ChatGPT works.
You can rotate the address The refresh button issues a new one and immediately invalidates the old.
Switching folders keeps the address Point it at another project without re-adding the connector in ChatGPT.
